# Technology Stack

## Overview
This trading bot project is built as a monorepo using Nx workspace, featuring multiple applications and shared libraries.

### Monorepo Management
- **Nx** (v20.4.6) - Monorepo build system and development tools
- **pnpm** - Package manager for efficient dependency management
- **TypeScript** (v5.7.3) - Primary programming language
